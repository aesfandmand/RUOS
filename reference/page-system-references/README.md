# Page-system references — sent 2026-10-13

Eight full-page compositions. §12–§14 cover cards and row rhythm; this set is
about **whole-page structure** — what a complete, developed page looks like from
hero to footer.

| # | File | What to take from it |
|---|---|---|
| 01 | `vector-systems-b2b-industrial` | The closest match to our own page type. Hero photo with a scrim, a philosophy row (text one side, photo the other, trust icons under the text), three photo cards each carrying its number and a round arrow button, a four-step numbered strip, a single coloured closing band. If a service or solution page needs a skeleton to argue with, start here. |
| 02 | `elysian-bento-stat-grid` | An asymmetric bento mixing photographs and number cards in one grid — the proof section without a boring stat row. |
| 03 | `aurel-12col-system-board` | Desktop and mobile shown side by side with the 12-column grid and the XS–XL scale made explicit. This is how a page should be specified, not just drawn. |
| 04 | `aero-step-category-tiles` | Large category tiles with a photo bleeding off one edge and the label in the clear corner — a strong alternative to a uniform card grid. |
| 05 | `bauen-architecture-dark` | Section rhythm and the two-up project row. Dark; see the colour note below. |
| 06 | `furniture-icon-step-row` | An icon row joined by a rule with dots — a lighter way to show three stages than three cards. |
| 07 | `ecommerce-split-hero-blocks` | A hero split into an ink panel and a photo panel at unequal widths. |
| 08 | `find-home-chips-and-overlay-cards` | Filter chips above a card rail, and the two card treatments side by side. |

**Colour:** 05 and 07 are dark. §1 is unchanged — take the composition, not the
ground.

**Numbers and ratings:** 01, 02 and 08 all carry figures we have no verified
equivalent for. §3 governs: tagged placeholder, never an invented value. There
are no star ratings on our pages.
