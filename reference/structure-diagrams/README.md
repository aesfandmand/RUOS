# Structure assembly diagrams

Owner-supplied technical references (2026-08-14), used to verify what real
installation photos in `reference/didanshow-photos/raw/` actually show —
these are CAD renders, not real installation photography, so they don't go
into `media/structures/<ID>/` as gallery/hero images.

- `strabord-4x3-exploded-assembly.jpg` — exploded 3D view of a single
  center-pole strabord: concrete base, pole, top crossbar, side struts
  holding the panel face(s).
- `strabord-4x3-dimensions.jpg` — the same assembly, labeled: "استرابورد دو
  وجهی یا تک وجهی با ابعاد ۳×۴ متر و ارتفاع تاج ۶.۵ متر" (single- or
  double-face strabord, 3×4m, 6.5m crown height) — matches STR-004
  (استرابورد عمودی ۴×۳).

This resolved a real misfiling: the side struts visible in these diagrams
were first mistaken (in photos, without this reference) for floodlight
fixtures, which had put two real strabord photos under STR-008 (برایت‌بورد)
instead of STR-004. See `reference/didanshow-photos/README.md` for the
correction.
