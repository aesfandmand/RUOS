# Real structure photography

Real, non-AI photographs of physical structures, organized by registry
structure ID. Source: Didanshow (دیده‌شو), the project owner's own OOH
company — see `reference/didanshow-photos/README.md` for the full
provenance and the caption rule (credit the installation photo to
Didanshow; never imply the ad creative shown on the board face is
Chatreghermez's own client work).

Each `STR-###/` directory holds photos confirmed (by visual inspection,
not filename) to show that specific structure. A structure with no
directory here has no confirmed real photo yet — its detail page falls
back to the CSS-drawn dimension diagram rather than a fabricated image.
