## Verification rule

پیش از هر ارتقای ابزار از `provisional` به `validated` باید این موارد دوباره بررسی شوند:

- current license file
- supported release and security policy
- RTL and Persian behavior
- Mobile Safari behavior
- bundle and performance impact
- maintenance and breaking-change risk
- compatibility with the selected Red Umbrella build profile
