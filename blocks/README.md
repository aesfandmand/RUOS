# Block Library

هر بلوک یک الگوی ترکیب‌بندی مستقل است، نه یک کامپوننت تزئینی. کیفیت سقفِ هر
صفحه‌ای که موتور می‌سازد، برابر است با کیفیت همین کتابخانه — نه با هوشمندی
مرحلهٔ تولید. بنابراین بالا بردن کیفیت خروجی یعنی افزودن و پالودن بلوک، نه
افزودن لایهٔ تصمیم‌گیری بیشتر.

## ساختار هر بلوک

```
blocks/<id>/
├── block.json    قرارداد: خانواده، سطح، نیت، اسلات‌های داده، قواعد مجاورت
├── style.css     CSS محدود به همین بلوک
└── behavior.js   اختیاری؛ فقط اگر block.json مقدار behavior=true داشته باشد
```

قراردادها JSON هستند نه YAML، چون موتور باید بدون هیچ وابستگی خارجی نصب شود.

## منشأ

بلوک‌های فعلی از `builds/structures-final/index.html` استخراج شده‌اند؛ همان صفحه‌ای
که دستی نوشته شده بود و کیفیتش تأیید شده بود. تقسیم CSS بدون از دست رفتن حتی یک
اعلان انجام شد و مسیر منبع هر بلوک در `source` قرارداد ثبت است.

جاهایی که عمداً از منبع فاصله گرفته‌ایم، در خودِ فایل CSS با کامنت علامت خورده‌اند
(هر سه مورد: نوار فهرست مستقل، skip-link، و اندازهٔ هدف لمسی لینک‌های درون‌خطی).

## قواعدی که کامپوزیتور اجبار می‌کند

این‌ها در `src/ruos/block_composer.py` پیاده شده‌اند و build را رد می‌کنند، نه اینکه
فقط هشدار بدهند:

| قاعده | چرا |
|---|---|
| دو بلوک هم‌خانواده نمی‌توانند کنار هم بیایند | جلوگیری از صفحه‌ای که فقط ردیف کارت است |
| بیش از دو سطح هم‌رنگ پشت سر هم ممنوع | ریتم بصری؛ چشم نباید خسته شود |
| صفحه باید با `position: first` باز و با `position: last` بسته شود | هر صفحه یک ورود و یک مسیر تبدیل دارد |
| اسلات اجباری غایب، فهرست خارج از بازه، یا اسلات ناشناخته | داده باید با قرارداد بخواند |
| فقط CSS و JS بلوک‌های واقعاً استفاده‌شده وارد خروجی می‌شود | صفحه چیزی را حمل نمی‌کند که ندارد |

## افزودن بلوک تازه

1. پوشه با `block.json` و `style.css` بسازید.
2. یک مولد markup در `src/ruos/block_library.py` ثبت کنید و در `RENDERERS` بیاورید.
3. تست‌ها خودشان بررسی می‌کنند که هر قرارداد یک مولد دارد و برعکس.

## ساخت یک صفحه

```bash
ruos compose structures                 # از pages/blocks/structures.json
ruos compose structures --output dist   # خروجی در dist/structures/
```

## مرزی که هنوز رد نشده

انتخاب خودکار بلوک از روی نیت صفحه هنوز پیاده نشده؛ فعلاً توالی بلوک‌ها در اسپک
صفحه صریح اعلام می‌شود و کامپوزیتور آن را اعتبارسنجی می‌کند. این تصمیم عمدی است:
اعتبارسنجی قابل‌اتکا مقدم بر انتخاب خودکاری است که هنوز شواهدی برای درستی‌اش نداریم.
